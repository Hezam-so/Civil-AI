قارئ وعارض ملفات DWG والمخططات الهندسية

افتح ملف AutoCAD DWG الأصلي، اعرض لوحات 2D والنماذج 3D المتاحة، اختر العناصر واقرأ خصائصها وطبقاتها. تستخدم المعاينة خدمة Autodesk APS؛ لا يقوم المتصفح بتحليل DWG الثنائي مباشرة.

الملف يُرفع إلى خدمات Autodesk السحابية للتحويل، وقد تُطبّق تكاليف استخدام واحتفاظ بالبيانات. لا ترفع مخططات سرية أو تخص عميلًا دون موافقته. هذا العارض لا يجري تحليل قوى أو تصميم إنشائي ولا يفتح Robot RTD مباشرة. قد يتطلب Civil 3D Object Enabler وقد لا تُترجم جميع الكائنات.
