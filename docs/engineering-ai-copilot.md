# Civil AI Engineering Copilot — Scope and Operation

## Pages
- `/assistant.html`: main AI copilot with calculator and optional image attachment
- `/api/assistant`: authenticated API for engineering calculations and optional Vercel AI Gateway chat
- Home and Studio menus link to the same assistant.

## Available verified calculation routines
1. Simply supported beam, full-span UDL (`R=wL/2`, `Mmax=wL²/8`).
2. Simply supported beam, point load at midspan (`R=P/2`, `Mmax=PL/4`).
3. Rectangular concrete volume with optionally specified waste and unit cost.
4. Average soil contact pressure for vertical concentric loading (`P/A`) only.
5. Theoretical steel reinforcement weight from diameter, length and density.
6. Area, Ix and elastic Zx of a solid rectangular section.
7. Length/force/pressure/area unit conversion.

All numerical routines validate input ranges and return assumptions. They are NOT code-compliant structural design and do not conduct FEM, soil settlement, detailing checks, or DWG/RVT/RTD analysis.

## AI mode (Vercel AI Gateway)
The server uses the compatible `/v1/chat/completions` endpoint and defaults to `openai/gpt-5.4-mini` (verified in the public model catalog as of November 2026). It selects `AI_GATEWAY_API_KEY` if available or uses the deployment-provided `VERCEL_OIDC_TOKEN`. A team may need to set up Gateway billing/credits or create a gateway key; the project does not contain a provider key and does not expose one to browsers.

Override model by setting the sensitive Vercel environment variable `CIVIL_AI_AI_MODEL` to a compatible `provider/model` ID, then redeploy. The model should support image and tool inputs when users use both features.

Without AI Gateway authorization, the calculator and a limited navigation helper still work. Do not claim free-form AI answers are active merely because the UI is deployed.

## Account security and user data
- POST requires the same origin and a valid signed account cookie, checked against the user's current private Vercel Blob account record and session version.
- Numeric tools do not require paid model inference.
- AI calls are limited to 12/user/day with best-effort private Blob records; concurrent requests may bypass the exact limit, so stronger atomic/distributed quotas are required for high-traffic public usage.
- The API never evaluates JavaScript generated by a model.
- Model actions only return allowlisted *proposals*. They require a user-initiated confirmation in the frontend and never save/delete or send user projects.
- Chat conversations remain in memory on the page and are not persisted by this implementation.
- User text and explicitly selected images are sent to AI Gateway/model providers when enabled; do not upload sensitive client documents without authorization.

## Manual smoke tests
1. Open the site, log in, click the assistant menu.
2. Check `GET /api/assistant` status. An `enabled:true` flag means credentials are present, not that Gateway billing and model access have been verified.
3. In the calculator: UDL 6m, 10 kN/m should yield R=30 kN, Mmax=45 kN·m; 5×4×0.2m with 5% waste should yield 4.2m³.
4. Ask an engineering question and check that the model uses a deterministic tool for numeric outputs; if unavailable, inspect the error and configure Gateway.
5. Ask to open the rebar tool. Confirm a user approval is required, then verify Studio opens.
6. Ask to fill home beam values; verify explicit approval then numerical limits, navigation, and editable fields.
7. Try unsupported input, huge values and a PDF attachment; these must be rejected or clearly explained.
8. Confirm projects are not overwritten merely by asking the assistant to calculate.
